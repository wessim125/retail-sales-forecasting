# Retail Sales Forecasting

Projet de prévision des ventes pour Rossmann.

## Structure

- `data/raw/` : fichiers bruts de la compétition
- `data/processed/` : données nettoyées et enrichies
- `notebooks/` : explorations et analyses
- `src/` : code de features, validation et entraînement
- `reports/` : graphiques, métriques et résultats

## Objectif

Prédire les ventes journalières de 1 115 magasins avec une validation temporelle stricte et un dashboard de suivi.

## Démarrage

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
